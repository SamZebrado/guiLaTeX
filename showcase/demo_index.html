Web v1

已公开发布的主产品线：文本、图片、受限公式、持久分组、撤销/重做、项目保存/打开、IR、conforming LaTeX 与 Chromium PDF。

Project authority

项目 JSON 是无损编辑权威。Conforming LaTeX 面向 guiLaTeX 自己生成的单页格式，不是任意 LaTeX 导入器。

Supporting routes

Qt 是次要桌面原型；ExportCore 提供共享协议、校验和 roundtrip 支撑，不作为独立产品。

GitHub Pages 提供项目展示与发布说明，不是完整在线编辑器。完整 Web v1 需要从仓库运行 python3 web_prototype/server.py，因为 LaTeX import/export 使用本地 loopback server 与 ExportCore。
